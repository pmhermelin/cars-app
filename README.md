# cars-app — מערכת סוכנות רכבים

מערכת Console בשפת C# לניהול סוכנויות רכבים ואופנועים: לקוחות מחפשים רכבים ומזמינים אותם לרכישה או להשכרה, אנשי מכירות מנהלים את המלאי ויוצרים עסקאות, ומנהלי סוכנויות מאשרים או דוחים עסקאות ומפיקים דוחות.

הפרויקט נבנה במסגרת הקורס "ניהול ופיתוח פרויקטי תוכנה" (הנדסאי תוכנה), לפי מסמך הדרישות ומסמך העיצוב הטכני ב-Confluence.

**אילוצי המימוש** (מסמך העיצוב, פרק 3):
- מערכים בגודל קבוע בלבד, בלי `List` ואוספים דינמיים
- הרכבה (Composition) בלבד, בלי ירושה ובלי `interface`
- כל הנתונים נשמרים בזיכרון ונמחקים בסיום הריצה; אין בסיס נתונים, קבצים או רשת
- כל שדה `private`, וגישה רק דרך מתודות; לסיסמה אין getter

## דרישות והרצה

נדרש [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bash
git clone https://github.com/pmhermelin/cars-app.git
cd cars-app
```

| פעולה | פקודה |
| --- | --- |
| הרצת המערכת | `dotnet run` |
| הרצת הבדיקות | `dotnet run -- test` |
| בנייה בלבד | `dotnet build` |

ב-Visual Studio 2022: **File ← Open ← Project/Solution** ובוחרים את `CarsApp.csproj`.

הבדיקות נמצאות ב-`Tests.cs`, ושם כל בדיקה מתחיל במספר שלה מתוכנית הבדיקות במסמך העיצוב (T-01 עד T-28). בסוף הריצה מודפס `Passed: X, Failed: 0`.

## מבנה הקוד

| קובץ | תפקיד |
| --- | --- |
| `Program.cs` | נקודת הכניסה; תפריטים, קליטת קלט והודעות בלבד, בלי לוגיקה עסקית |
| `CarDealerShipSystem.cs` | מחלקת השירות המרכזית: מחזיקה את כל המערכים, אוכפת הרשאות וכללים עסקיים |

## תפקידים ותפריטים

במערכת 5 סוכנויות קבועות שנוצרות בהפעלה: 3 של רכבים ו-2 של אופנועים. לקוח ומנהל נרשמים דרך מסך ההרשמה; מנהל בוחר סוכנות שעדיין אין לה מנהל. **איש מכירות נוצר רק על ידי מנהל הסוכנות.**

**תפריט ראשי:** 1. הרשמה (REQ-001) · 2. התחברות (REQ-002) · 3. יציאה

## מחזור חיי הזמנה ורכב

```
יצירת הזמנה (REQ-011)
   הזמנה: Pending        רכבים: Available → Reserved
        │
        ├── ביטול ע"י הלקוח (REQ-004)   → הזמנה: Cancelled   רכבים: → Available
        ├── דחייה ע"י המנהל (REQ-005)   → הזמנה: Rejected    רכבים: → Available
        └── אישור ע"י המנהל (REQ-005)   → הזמנה: Approved    רכבים: → Sold (רכישה) / Rented (השכרה)
```

- הסטטוסים Approved, Rejected, Cancelled, Sold ו-Rented סופיים.
- הרכבים משנים סטטוס רק אחרי שמעבר הסטטוס של ההזמנה הצליח.
- **מגבלות לקוח:** רכב אחד לכל היותר ברכישה פעילה, ועד 3 רכבים בהשכרה פעילה (הזמנות Pending ו-Approved).
- כל הרכבים בהזמנה אחת שייכים לאותה סוכנות ולאותו סוג עסקה.
